# Reference evidence

Captured contracts belong here, with CLI version, executable SHA-256, timestamp,
model and capture scope. These are reference observations, not automatically
approved compatibility profiles. A fixture may intentionally produce DIFF.

The `2.1.156` gateway fixture was captured with synthetic credentials and a local
SSE server. It predates the bundled 2.1.282 profile and is diagnostic evidence,
not a supported-version claim or a direct OAuth acceptance test.
